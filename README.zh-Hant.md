## Getting Started

This development toolkit contains all environments and tools needed to develop extensions for [JLCEDA Pro Edition](https://pro.easyeda.com/), and includes the recommended ESLint rules out of the box.

1. Clone the [pro-api-sdk](https://github.com/easyeda/pro-api-sdk) project repository locally

    ```shell
    git clone --depth=1 https://github.com/easyeda/pro-api-sdk.git
    ```

2. Initialize the development environment (install dependencies)

    ```shell
    npm install
    ```

3. Make some changes...

4. Build the extension package

    ```shell
    npm run build
    ```

5. Install the extension package generated under `./build/dist/` in JLCEDA Pro Edition
