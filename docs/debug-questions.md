- 主流程超时后继续，使用 L2/L3/L4 策略
- 网表在后台继续获取，完成后自动回填
- 详见：`/home/ubuntu/netlist-backfill-guide.md`

**提交记录**：`9b2ea08 feat: 实现网表延迟回填机制`

## 可能的解决方案
