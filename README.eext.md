# EasyEDA AI Assistant

基于嘉立创 EDA 专业版的 AI 原理图对话助手。

## 功能特性

- AI 对话助手 - 与 AI 对话，分析原理图设计
- 智能数据采集 - 自动采集原理图数据（器件、引脚、网络）
- Pin-Net 绑定 - 基于网表的引脚-网络绑定
- 网表解析 - 支持 PROTEL NETLIST 2.0 格式
- 流式响应 - 实时显示 AI 思考过程和回答
- 智能跳转 - 点击蓝色标签直接定位到原理图元件
- 历史记录 - 自动保存对话历史

## 安装

1. 打开嘉立创 EDA 专业版
2. 进入 扩展 → 扩展管理器
3. 搜索 "AI Schematic Assistant"
4. 点击安装
5. 重启 EasyEDA Pro

## 使用

1. 打开原理图
2. 点击菜单 AI Review → AI 原理图助手
3. 配置 AI API（API URL 和 API Key）
4. 开始与 AI 对话
